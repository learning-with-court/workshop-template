# Example Workshop

## What you'll make

A tiny piece of TypeScript: one function that returns a greeting. It is small on purpose, so you can see how a lesson works before the lessons get real.

## How it works

Each lesson is a short list of steps on this page. Every step has one thing to ask Claude, with a button that sends it for you. Claude does the typing in the terminal beside this page, and the step fills in with what it ran and what came back. When you've read it, press **Next step**.

A lesson ends with a recap of what you did and a check that it all works. When the check passes, the next lesson opens.

## What you'll do, in one lesson

1. **Your first function.** Read a test, write the function it asks for, and watch it run.
